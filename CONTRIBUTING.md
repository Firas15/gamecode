# Как подключиться к разработке GameCode

Инструкция для нового участника команды. Занимает минут двадцать.

## Что понадобится

Всего две программы:

- **Git** — [git-scm.com](https://git-scm.com/)
- **Docker Desktop** — [docker.com](https://www.docker.com/products/docker-desktop/)

Плюс редактор кода (у команды VS Code, но это дело вкуса) и аккаунт на GitHub — попросите владельца репозитория добавить вас в соавторы.

**PostgreSQL, PHP, Apache и Redis ставить не нужно.** Они живут внутри контейнеров, Docker поднимет их сам. На вашем компьютере от проекта останется только папка с кодом.

> Команды ниже даны в двух вариантах, где синтаксис различается. Строки с `psql` выполняются **внутри контейнера** — это то, что делает `docker compose exec`.

## 1. Забрать код

```bash
git clone https://github.com/Firas15/gamecode.git
cd gamecode
```

## 2. Создать локальные настройки

Файлы с паролями в репозиторий не попадают, поэтому их нужно создать у себя. Пароли придумайте **свои**, боевые для локальной разработки не нужны.

**Linux и macOS:**
```bash
cp .env.example .env
cp admin/config.example.php admin/config.php
mkdir -p db/init && cp db/schema.sql db/init/00-schema.sql
```

**Windows (PowerShell):**
```powershell
Copy-Item .env.example .env
Copy-Item admin\config.example.php admin\config.php
New-Item -ItemType Directory -Force db\init | Out-Null
Copy-Item db\schema.sql db\init\00-schema.sql
```

Последняя команда кладёт структуру базы туда, откуда PostgreSQL выполнит её при первом запуске. Каталог `db/init` в репозиторий не попадает намеренно: на боевом сервере там лежит полный дамп, и два файла со схемой конфликтовали бы между собой.

Откройте `.env` и задайте:

| Переменная | Что вписать |
|---|---|
| `POSTGRES_PASSWORD` | любой пароль |
| `DB_PASSWORD` | **тот же самый** — иначе приложение не подключится к базе |
| `ADMIN_PASSWORD` | пароль для входа в админку |
| `WEB_PORT` | `8080`, чтобы не занимать 80-й порт |

## 3. Запустить

```bash
docker compose up -d --build
```

Первый запуск занимает несколько минут: скачиваются образы и собирается PHP с расширениями. При первом старте база сама выполнит `db/schema.sql` и создаст пустые таблицы.

Открыть: **http://localhost:8080**

Сайт заработает, но база будет пустой. Наполните её демо-данными:

```bash
docker compose cp db/seed-demo.sql db:/tmp/seed.sql
docker compose exec db psql -U gamecode_user -d gamecode -f /tmp/seed.sql
```

Эти две команды одинаковы на всех системах. Через `<` файл подавать не стоит: в PowerShell такое перенаправление не работает.

Появятся все четыре игры, 100 вопросов викторины с вариантами ответов, справочник чат-бота, новости и уровни Pixelgame. Учётных записей и результатов игроков там нет — это боевые персональные данные, они в репозиторий не попадают. Свой аккаунт заведите через обычную регистрацию на сайте.

## 4. Внести правку

```bash
git checkout -b короткое-имя-задачи
# правите файлы, проверяете на localhost:8080
git add -A
git commit -m "Что сделано"
git push -u origin короткое-имя-задачи
```

Дальше на GitHub создайте Pull Request в `main`.

**Почему через ветку, а не сразу в main.** Сервер каждые две минуты проверяет `main` и, увидев новый коммит, автоматически выкладывает его на боевой сайт. То есть пуш в `main` — это публикация. Ветка и Pull Request дают возможность посмотреть изменения до того, как их увидят пользователи.

## Полезные команды

```bash
docker compose logs web --tail 50    # ошибки PHP
docker compose logs db  --tail 50    # проблемы с базой
docker compose restart web           # перезапустить приложение
docker compose down                  # остановить всё
docker compose down -v               # остановить и стереть базу (начать с нуля)
```

## Чего делать не нужно

- **Не коммитьте** `.env`, `config.php`, `admin/config.php`, дампы базы. Они в `.gitignore`, но если добавите принудительно через `git add -f` — пароли окажутся в публичном репозитории навсегда, даже после удаления файла.
- **Не пушьте в `main` непроверенное.** Через две минуты это увидят пользователи.
- **Не редактируйте файлы прямо на сервере.** Следующий автодеплой их затрёт.
