# Глюк-атака — 5-я игра GameCode

Глюк-призраки атакуют сервер GameCode. У каждого вопрос по IT. Ответ — выстрел пушки:
верно — призрак рассыпается, ошибка или опоздание — минус жизнь. В конце босс «Глюк-ядро».

Управление: `1`–`4` или клик/тап по ответу, `P` / `Esc` — пауза.

## Как устроено

| Где | Что |
|---|---|
| `games/glitch/index.html`, `css/`, `js/` | сама игра: экраны, поле на canvas, звук на Web Audio |
| `js/game.js` | экраны, волны, босс, итоги; все тайминги — в `CONFIG` вверху |
| `js/render.js` | поле: призраки (перенос `drawMonster`, тип 2, из CodeQuest; цвет = цвет темы), пушки, лазеры, сервер, Пиксель |
| `js/audio.js` | 8-битные эффекты и музыка, без файлов |
| `api/glitch.php` | сервер партии: темы → старт → вопрос → ответ |
| `includes/glitch.php` | общая логика: план партии, баланс очков, состояние в сессии |
| `admin/glitch.php` | админка: вопросы и темы |
| `db/migrations/004-glitch.sql` | таблицы `glitch_themes`, `glitch_questions`, 50 стартовых вопросов, строка в `games` |
| `db/migrations/005-glitch-questions.sql` | ещё 90 вопросов — всего 140, по 20 на тему; заливается один раз (`glitch_seeds`) |

Очки, рейтинг, пиксель коины и окно «сохранить результат» для гостя — общие для всех игр сайта
(`js/leaderboard.js` → `api/ping-game.php` / `api/score.php`).

## Защита от накрутки

Партию ведёт сервер, браузер только рисует:

1. `ping-game.php` выдаёт подписанный ран (как у всех игр).
2. `glitch.php?start` — сервер сам выбирает вопросы и раскладывает их по волнам. Браузер получает только темы.
3. `next` — один вопрос и 4 варианта в перемешанном порядке. **Правильного ответа в ответе сервера нет.**
4. `answer` — браузер присылает номер варианта. Сервер проверяет, считает очки по своим часам, жизни, серию, босса
   и только теперь говорит, какой вариант был верным.
5. `score.php` берёт итог из состояния партии в сессии. Payload от браузера для этой игры не используется вообще.

Дополнительно: ответ раньше, чем призрак вышел на позицию, отклоняется; ответ сильно позже таймера
засчитывается без очков; партию нельзя сдать быстрее честного минимума (≈80 % от суммы анимаций),
а ран — сдать дважды.

## Баланс (includes/glitch.php)

- 5 волн по 4 призрака + босс на 3 вопроса = 23 вопроса, 3–4 минуты.
- Время на вопрос по волнам: 18 / 16 / 14 / 12 / 10 с, у босса 12 с.
- Верный ответ: 20 + до 10 за скорость + бонус серии (+5 / +10 / +15 при серии 3 / 6 / 9).
- Босс: +50 за попадание, +100 за победу над ним. Идеальная партия ≈ 1000 очков, коины — 10 %.
- 4 жизни. Партия начинается, если в выбранных темах не меньше 10 видимых вопросов.

## Вопросы

Правятся в админке → «ГЛЮК-АТАКА»: добавить, изменить, скрыть, удалить; темы — название, цвет, порядок, скрыть.
Игра читает базу на каждой партии, кэша нет. Короткие тексты читаются лучше: вопрос до ~90 символов, вариант до ~40.

Стартовые 50 вопросов — из викторины для мероприятия. Исправлено относительно исходника:
№37 (первый байт UTF-8 показывает длину символа), перепутанные ответы №19/№20 (UEFI), опечатки в №4, №9, №42.

Ещё 90 — из «Викторина — новые вопросы» (миграция 005). Неверные варианты и пояснения дописаны.
Вопрос «Чем список отличается от кортежа?» повторял стартовый про кортеж, поэтому заменён на
«Что из этого может быть ключом словаря?» (та же тема — изменяемость, но другой факт).
Удалённый или исправленный в админке вопрос миграция 005 обратно не вернёт.
