# Сетевой маршрут

Игра про IP-адресацию. Правило оформления: везде пиксельный шрифт (лежит локально, из «Глюк-атаки») и никаких эмодзи. Геккон-сисадмин дежурит у сети, игрок доводит пакеты до цели: решает задания на время, за ошибку теряет жизнь. После каждого ответа геккон объясняет, почему верно именно так, в конце — разбор всех ошибок.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html`, `css/`, `js/game.js` | экраны: меню, «как играть», игра, итоги |
| `assets/img/admin-*.png` | геккон-сисадмин (кадры геккона из «Глюк-атаки», перекрашены, гарнитура и бейдж) |
| `includes/network.php` | генератор заданий, уровни, очки |
| `api/network.php` | сервер партии: уровни → старт → задание → подсказка → ответ |
| `admin/network.php` | админка: теория и примеры сгенерированных заданий |
| `db/migrations/006-network.sql` | таблица `network_questions` и 42 вопроса теории |

## Задания

Числовые задания генерирует сервер — каждый раз новые адреса и всегда верный ответ:

| Тип | Что спрашивается |
|---|---|
| Свой или чужой | кликнуть устройство из своей подсети (или найти чужое) |
| Адрес сети / Broadcast | первый и последний адрес подсети |
| Сколько узлов | сколько устройств поместится в сеть /N |
| Маска | префикс ↔ маска |
| Шлюз | какой адрес годится в шлюзы |
| Частный или публичный | «серые» и «белые» адреса |
| Найди поломку | у одного из 4 устройств чужая подсеть, неверная маска, шлюз не из сети, адрес сети или broadcast |
| Маршрутизация | куда уйдёт пакет по таблице роутера (самый длинный префикс) |
| Теория | вопрос из базы (DNS, DHCP, NAT, порты, OSI…) |

## Уровни и очки

На любое задание — 60 секунд, на всех уровнях.

| Уровень | Заданий | Очки за ответ | Бонус за уровень | Максимум |
|---|---|---|---|---|
| Новичок (/24) | 8 | 30 + до 15 за скорость | 50 | ≈ 455 |
| Практик (/8, /16, шлюзы, поломки) | 10 | 40 + до 20 | 80 | ≈ 755 |
| Эксперт (/25–/30, маршрутизация) | 10 | 60 + до 25 | 120 | ≈ 1045 |

- Серия верных подряд: +5 на 3-м, +10 на 6-м, +15 на 9-м ответе.
- 3 жизни. Ответ позже таймера (с запасом 3 с на сеть) засчитывается, но без очков.
- Калькулятор показывает адреса в двоичном виде и подсвечивает биты сети. Задание с подсказкой — половина очков.

## Защита от накрутки

Как у «Глюк-атаки»: партию целиком ведёт сервер. Браузер получает задание без ответа и присылает только номер выбранного варианта; сервер проверяет ответ, считает время по своим часам, очки и жизни. `api/score.php` берёт итог из состояния партии в сессии. Ответ быстрее 0,5 с отклоняется, партию нельзя сдать быстрее, чем она физически проходится.

## Проверка генератора

Каждый тип задания прогонялся десятки тысяч раз с независимой проверкой ответа (ровно один верный вариант, варианты не повторяются). При правке `includes/network.php` стоит повторить такую проверку.
