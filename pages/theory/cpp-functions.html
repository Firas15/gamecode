Объявление, параметры, return

C++ Практик

[ ОБЪЯВЛЕНИЕ ФУНКЦИИ ]

В C++ функцию нужно объявить до её использования. Указываем тип возвращаемого значения, имя и параметры.

C++
// тип_возврата имя(параметры)
int add(int a, int b) {{
    return a + b;
}}

void greet(string name) {{   // void — ничего не возвращает
    cout << "Привет, " << name << endl;
}}

int main() {{
    int result = add(10, 25);
    cout << result << endl;    // 35
    greet("Mark");             // Привет, Mark
    return 0;
}}

[ ПРОТОТИП ФУНКЦИИ ]

Если хочешь написать функцию после main(), объяви её прототип (сигнатуру) в начале файла.

C++
#include <iostream>
using namespace std;

int square(int n);   // прототип

int main() {{
    cout << square(5) << endl;   // 25
    return 0;
}}

int square(int n) {{   // определение
    return n * n;
}}

[ ПАРАМЕТРЫ ПО УМОЛЧАНИЮ ]

C++
void level_up(string name, int bonus = 10) {{
    cout << name << " получает +" << bonus << " опыта" << endl;
}}

level_up("Mark");      // Mark получает +10 опыта
level_up("Bob", 25);   // Bob получает +25 опыта

[ ПОПРОБУЙ САМ ]

₊⊹ЗАДАНИЕ

Напиши функцию max(a, b), которая возвращает большее из двух чисел. Вызови её три раза: max(3,7), max(10,5), max(4,4).

[ ПОКАЗАТЬ РЕШЕНИЕ ] 
int max(int a, int b) {{
    return (a > b) ? a : b;
}}

main: cout << max(3,7)  // 7
       cout << max(10,5) // 10
       cout << max(4,4)  // 4
