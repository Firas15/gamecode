ВВОД И ВЫВОД

cout, cin и iostream

C++ Новичок

[ COUT — ВЫВОД ДАННЫХ ]

cout (character output) выводит данные в консоль. Оператор << передаёт данные в поток. endl или "\n" переносит строку.

C++
#include <iostream>
using namespace std;

int main() {{
    int    score = 150;
    string name  = "Mark";

    cout << "Hello, World!" << endl;
    cout << "Score: " << score << endl;
    cout << "Player: " << name << ", score = " << score << endl;
    return 0;
}}

[ CIN — ВВОД ДАННЫХ ]

cin считывает данные, введённые пользователем. Оператор >> помещает прочитанное в переменную.

C++
#include <iostream>
#include <string>
using namespace std;

int main() {{
    string name;
    int    age;

    cout << "Введи имя: ";
    cin  >> name;

    cout << "Введи возраст: ";
    cin  >> age;

    cout << "Привет, " << name << "! Тебе " << age << " лет." << endl;
    return 0;
}}
💡
Строки с пробелами: cin >> останавливается на пробеле. Для строки целиком используй getline(cin, name).
