ПЕРЕМЕННЫЕ И ТИПЫ

Объявление переменных в C++

C++ Новичок

[ ОБЪЯВЛЕНИЕ ПЕРЕМЕННЫХ В C++ ]

В отличие от Python, в C++ нужно явно указать тип переменной при объявлении. Тип нельзя изменить после объявления.

C++
// тип имя = значение;
int    score  = 100;
double pi     = 3.14159;
char   grade  = 'A';
bool   active = true;
string name   = "Mark";  // нужен #include <string>
₊⊹
Точка с запятой! Каждая инструкция в C++ заканчивается ;. Забытая точка с запятой — одна из самых частых ошибок новичков.

[ ОСНОВНЫЕ ТИПЫ ДАННЫХ ]

int
Целое число
-2 млрд .. +2 млрд
double
64-битное вещественное
3.14, -0.001
char
Один символ
'A', 'z', '5'
bool
Истина / ложь
true, false
string
Строка текста
"Hello"
float
32-битное вещественное
3.14f

[ КОНСТАНТЫ ]

Если значение не должно меняться, используй ключевое слово const. Попытка изменить константу вызовет ошибку компиляции.

C++
const int    MAX_HP   = 100;
const double PI       = 3.14159265;
const string GAME_VER = "1.0";

[ ПОПРОБУЙ САМ ]

₊⊹ЗАДАНИЕ

Объяви переменные для персонажа: имя (string), уровень (int), очки (double), живой ли (bool). Выведи все через cout.

[ ПОКАЗАТЬ РЕШЕНИЕ ] 
#include <iostream>
#include <string>
using namespace std;

int main() {{
    string hero  = "Mark";
    int    level = 5;
    double score = 97.5;
    bool   alive = true;

    cout << hero  << " level " << level << endl;
    cout << "Score: "  << score << endl;
    cout << "Alive: "  << alive << endl;
    return 0;
}}
