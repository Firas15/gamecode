Как пакеты путешествуют по сети

IP / Сети Практик

[ КАК УСТРОЙСТВА НАХОДЯТ ДРУГ ДРУГА ]

01
ПРОВЕРКА ПОДСЕТИ

Отправитель сравнивает свой IP и IP получателя с помощью маски подсети. Если адрес сети совпадает — получатель в одной сети, пакет идёт напрямую.

02
ЧЕРЕЗ ШЛЮЗ (РОУТЕР)

Если адрес сети не совпадает — пакет отправляется на шлюз по умолчанию (default gateway). Обычно это роутер с адресом .1 в подсети.

03
МАРШРУТИЗАЦИЯ

Роутер смотрит в таблицу маршрутов и передаёт пакет следующему устройству. Пакет прыгает от роутера к роутеру, пока не доберётся до цели.

ПРИМЕР
Компьютер A:  192.168.1.10 / маска 255.255.255.0
Компьютер B:  192.168.1.50 → одна сеть → напрямую ✓
Сервер C:     10.0.0.5     → разные сети → через роутер →
