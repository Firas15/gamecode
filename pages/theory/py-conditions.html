УСЛОВИЯ

if, elif, else, логика

PythonНовичок

[ IF / ELIF / ELSE ]

Условные конструкции позволяют выполнять разный код в зависимости от условия.

PYTHON
score = 75

if score >= 90:
    print("Отлично!")
elif score >= 60:
    print("Хорошо")    # ← выполнится это
elif score >= 40:
    print("Удовлетворительно")
else:
    print("Нужно повторить")

[ ТЕРНАРНЫЙ ОПЕРАТОР ]

Короткая запись if/else в одну строку — удобна для простых проверок.

PYTHON
score = 80
result = "победа" if score >= 60 else "поражение"
print(result)   # победа

[ ПОПРОБУЙ САМ ]

₊⊹ЗАДАНИЕ

Напиши функцию grade(score), которая возвращает оценку: 90+ → "A", 75+ → "B", 60+ → "C", иначе → "F".

[ ПОКАЗАТЬ РЕШЕНИЕ ] 
def grade(score):
    if   score >= 90: return "A"
    elif score >= 75: return "B"
    elif score >= 60: return "C"
    else:              return "F"
