ФУНКЦИИ

def, параметры и return

PythonНовичок

[ ЧТО ТАКОЕ ФУНКЦИЯ ]

Функция — это именованный блок кода, который выполняет определённую задачу. Написав функцию один раз, ты можешь вызывать её сколько угодно — это избавляет от повторений.

PYTHON
# Объявление функции
def greet():
    print("Привет, игрок!")

# Вызов функции
greet()    # Привет, игрок!
greet()    # Привет, игрок! — снова

[ ПАРАМЕТРЫ И АРГУМЕНТЫ ]

Параметры — переменные, которые функция принимает на вход. Аргументы — конкретные значения, которые ты передаёшь при вызове.

PYTHON
def greet(name, level):
    print(f"Привет, {name}! Твой уровень: {level}")

greet("Марк", 5)   # Привет, Марк! Твой уровень: 5
greet("Боб",   12)  # Привет, Боб! Твой уровень: 12

# Параметры со значением по умолчанию
def greet(name, level=1):
    print(f"Привет, {name}! Уровень {level}")

greet("Карл")         # Привет, Карл! Уровень 1

[ RETURN — ВОЗВРАТ ЗНАЧЕНИЯ ]

Функция может вычислить результат и вернуть его через return, чтобы использовать в других местах программы.

PYTHON
def add(a, b):
    return a + b

result = add(10, 25)
print(result)   # 35

def calc_score(correct, total):
    return round(correct / total * 100, 1)

print(calc_score(8, 10))  # 80.0

[ ВСТРОЕННЫЕ ФУНКЦИИ ]

Python поставляется с сотнями готовых функций. Самые частые:

print()
Вывод
print("hi")
len()
Длина
len("hello") => 5
int()
В целое
int("42") => 42
str()
В строку
str(7) => "7"
input()
Ввод
input("Имя")
range()
Диапазон
range(0,10)

[ ПОПРОБУЙ САМ ]

₊⊹ЗАДАНИЕ

Напиши функцию is_winner(score, target), которая возвращает True, если score >= target, и False иначе. Проверь: is_winner(85, 80) → True, is_winner(40, 60) → False.

[ ПОКАЗАТЬ РЕШЕНИЕ ] 
def is_winner(score, target):
    return score >= target

print(is_winner(85, 80))  # True
print(is_winner(40, 60))  # False
