print(5 != 3)   # True  — не равно

print(5 <  3)   # False — меньше

PYTHON
x = 10
x += 5    # x = x + 5  → 15
x -= 3    # x = x - 3  → 12
x *= 2    # x = x * 2  → 24
x //= 4   # x = x // 4 → 6
x **= 2   # x = x ** 2 → 36
x %= 7    # x = x % 7  → 1

[ ПОПРОБУЙ САМ ]

₊⊹ЗАДАНИЕ

Напиши выражение, которое проверяет, является ли число чётным (остаток от деления на 2 равен 0). Проверь для чисел 4, 7, 100, 13.

[ ПОКАЗАТЬ РЕШЕНИЕ ] 
def is_even(n):
    return n % 2 == 0

for n in [4, 7, 100, 13]:
    print(f"{n}: {is_even(n)}")
# 4: True  7: False  100: True  13: False
