print() и f-строки в Python

Python Новичок

[ ФУНКЦИЯ PRINT() ]

print() — встроенная функция Python, которая выводит информацию на экран (в консоль). Это первое, что ты пишешь в любой программе, чтобы увидеть результат своей работы.

PYTHON 
print("Привет, мир!")         # Привет, мир!
print(42)                     # 42
print(3.14)                   # 3.14
print(True)                   # True
print("Счёт:", 100)           # Счёт: 100
print("A", "B", "C", sep="-") # A-B-C
₊⊹
sep — разделитель между несколькими аргументами (по умолчанию пробел).
end — что добавить в конце (по умолчанию перенос строки \n).

[ ВЫВОД ПЕРЕМЕННЫХ ]

Чтобы вывести значение переменной, передай её имя в print() без кавычек. Можно объединять текст и переменные.

PYTHON 
name  = "Марк"
score = 150

# Способ 1 — через запятую
print("Игрок:", name, "Очки:", score)
# Игрок: Марк Очки: 150

# Способ 2 — конкатенация (склейка строк)
print("Игрок: " + name)
# Игрок: Марк

[ F-СТРОКИ ]

F-строки (форматированные строки) — самый удобный способ вставить переменную прямо в текст. Поставь букву f перед кавычками и оберни переменную в фигурные скобки {}.

PYTHON 
name  = "Марк"
level = 5
hp    = 87.5

print(f"Игрок {name} на уровне {level}")
# Игрок Марк на уровне 5

print(f"HP: {hp:.1f}%")   # форматирование — 1 знак после точки
# HP: 87.5%

print(f"2 + 2 = {2 + 2}")  # внутри {} можно писать выражения
# 2 + 2 = 4
✓ F-СТРОКА
print(f"Привет, {name}!")
✗ СТАРЫЙ СПОСОБ
print("Привет, " + name + "!")
