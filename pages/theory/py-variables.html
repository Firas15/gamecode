ПЕРЕМЕННЫЕ

Как хранить данные в Python

Python Новичок

[ ЧТО ТАКОЕ ПЕРЕМЕННАЯ ]

Переменная — это именованная ячейка в памяти компьютера, в которой хранится какое-либо значение. Представь коробку с наклейкой: наклейка — это имя переменной, а содержимое коробки — её значение.

В Python переменная создаётся в момент присваивания — никаких специальных слов вроде var или let не нужно.

PYTHON 
имя = значение
# Примеры:
age    = 17
name   = "Марк"
score  = 9.5
active = True
₊⊹
Знак = — это присваивание, а не равенство!
Он означает «запиши значение справа в переменную слева». Для проверки равенства используется ==.

[ ПРАВИЛА ИМЕНОВАНИЯ ]

Имя переменной может содержать буквы, цифры и знак подчёркивания _, но не может начинаться с цифры.

✓ ПРАВИЛЬНО
user_name  = "Боб"
score2     = 100
_hidden    = True
MAX_SPEED  = 300
✗ НЕПРАВИЛЬНО
2score   = 100   # цифра в начале
my-name  = "А"   # дефис запрещён
for      = 5     # зарезерв. слово
₊⊹
Стиль Python (PEP 8): используй snake_case — слова через подчёркивание строчными буквами: first_name, total_score.

[ ТИПЫ ДАННЫХ ]

Python автоматически определяет тип переменной по значению, которое ты ей присваиваешь.

int
Целое число
age = 17
float
Число с точкой
pi = 3.14
str
Строка текста
name = "Боб"
bool
Истина / ложь
ok = True
PYTHON 
# Функция type() показывает тип переменной
x = 42
print(type(x))   # <class 'int'>

y = "привет"
print(type(y))   # <class 'str'>

[ ИЗМЕНЕНИЕ ПЕРЕМЕННОЙ ]

Переменную можно изменить в любой момент — просто присвой ей новое значение. Можно даже сменить тип.

PYTHON 
score = 0
print(score)    # 0

score = 100
print(score)    # 100

score = score + 50   # прибавляем 50 к текущему значению
print(score)    # 150

# Сокращённая запись:
score += 10    # то же самое, что score = score + 10
print(score)    # 160

[ ПОПРОБУЙ САМ ]

₊⊹ ЗАДАНИЕ

Создай переменные для персонажа игры:
— hero_name = твоё имя
— hp = 100 (очки здоровья)
— level = 1
— alive = True

Потом выведи все переменные через print().

[ ПОКАЗАТЬ РЕШЕНИЕ ] 
hero_name = "Марк"
hp        = 100
level     = 1
alive     = True

print(hero_name)  # Марк
print(hp)         # 100
print(level)      # 1
print(alive)      # True
